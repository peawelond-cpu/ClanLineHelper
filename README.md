Raid line manager for **Fenrir Empire** clan | by **Eclipse**

## Команды
| Команда | Описание |
|---|---|
| `/36 Salvador` | Записать ник в позицию |
| `/-36` | Удалить ник |
| `/sdvig` | Сдвиг вниз |
| `/sdvigup` | Сдвиг вверх |
| `/copy` | Скопировать список |
| `/list` | Показать всё |
| `/clear` | Очистить |

## Установка
1. Установи Python 3
2. Запусти `Lain.py`
